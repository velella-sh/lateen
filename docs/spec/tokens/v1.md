# Lateen token spec, v1

This is the public promise for Lateen's design tokens. A name below is stable: it will not be renamed or
removed inside this spec version, and its type does not change. A site and a derived theme may read any of
them. A token not listed here is private.

The values come from `tokens/*.json` and are written to `styles/tokens.css` by `npm run tokens`. A preset
or `theme.options.brand` changes values, never names. The conformance script
([conformance.ts](conformance.ts)) reads this file and checks that an installed package declares every
token below with a value of the listed type.

## Types

| Type | Meaning |
| --- | --- |
| `color` | A colour, or `light-dark()` of two colours. |
| `length` | A CSS length, `clamp()` or `calc()` of lengths. |
| `number` | A unitless number. |
| `duration` | A time in `ms` or `s`. |
| `easing` | A `cubic-bezier()` or an easing keyword. |
| `shadow` | A `box-shadow` list. |
| `font-family` | A font stack. |
| `keyword` | A CSS keyword or a fill pattern name. |
| `integer` | A whole number, used for `z-index`. |
