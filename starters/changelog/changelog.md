:::changelog-entry{version="1.4.0" date="2026-06-18" categories="added,changed"}
- Add saved filters, so a search you use often is one click away.
- Make the import of large files about twice as fast.
- Change the default page size from 25 to 50 rows.
:::

:::changelog-entry{version="1.3.1" date="2026-05-27" categories="fixed"}
- Fix exports that dropped the last row when a file ended without a newline.
- Fix the date column, which showed the previous day in some time zones.
:::

:::changelog-entry{version="1.3.0" date="2026-05-06" categories="added,security"}
- Add shared views, which let a team keep one set of columns and filters.
- Require a fresh sign-in before a view is made public.
:::

:::changelog-entry{version="1.2.0" date="2026-03-24" categories="added,removed"}
- Add a dark theme that follows the system setting.
- Remove the old CSV layout that was deprecated in 1.1.0.
:::

:::changelog-entry{version="1.1.0" date="2026-02-10" categories="added,fixed"}
- Add keyboard shortcuts for moving between rows.
- Fix the footer, which covered the last row on small screens.
:::
