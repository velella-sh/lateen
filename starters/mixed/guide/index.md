Choose a [station](../stations/) and note its instrument. Write down the time, the instrument's
reading and unit, and any conditions that could affect the reading. Start at the [Ridge station](../stations/ridge/)
if you are practising a wind observation.

To change these instructions, edit this Markdown file. To add a station, add a key and its fields to
`_data/stations.yml`. The catalogue and the station page will update together.
