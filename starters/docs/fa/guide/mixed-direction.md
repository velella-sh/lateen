متن فارسی از راست به چپ خوانده می‌شود، اما نام دستورها، مسیرها و کد همیشه از چپ به راست می‌مانند. برای مثال، دستور `sandbar run test` را در میان جمله بنویسید و مسیر `src/index.ts` را هم همین‌طور؛ هر دو درست نمایش داده می‌شوند.

یک جمله با عبارت انگلیسی: فایل Task File در ریشهٔ پروژه قرار می‌گیرد و پس از اجرای `sandbar list` فهرست کارها چاپ می‌شود.

بلوک کد همیشه چپ‌به‌راست است، حتی میان دو بند فارسی:

```bash
npx sandbar run build --dry-run
```

:::callout{type=tip title="نکته"}
نام دستور را داخل بک‌تیک بگذارید تا جهت آن حفظ شود، و اعداد را همان‌طور که در خروجی ابزار می‌آیند، مثلاً `--parallel 2`، بنویسید.
:::
