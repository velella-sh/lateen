## `sandbar run <task>`

یک کار و کارهایی را که پیش از آن باید اجرا شوند اجرا می‌کند.

| گزینه | پیش‌فرض | کار |
| --- | --- | --- |
| `--keep-going` | خاموش | کارهایی را که به کار ناموفق وابسته نیستند ادامه می‌دهد. |
| `--dry-run` | خاموش | ترتیب اجرا را بدون اجرا چاپ می‌کند. |

## `sandbar list`

همهٔ کارهای `sandbar.yml` را، هر کدام در یک خط، چاپ می‌کند.

## `sandbar init`

یک `sandbar.yml` اولیه در پوشهٔ جاری می‌نویسد و فایل موجود را هرگز بازنویسی نمی‌کند.

:::callout{type=warning title="کدهای خروج"}
`0` یعنی همهٔ کارها موفق بودند، `1` یعنی یک کار شکست خورد و `2` یعنی فایل کارها نامعتبر است.
:::
