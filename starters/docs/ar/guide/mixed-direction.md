يُقرأ النص العربي من اليمين إلى اليسار، أما أسماء الأوامر والمسارات والشيفرة فتبقى دائمًا من اليسار إلى اليمين. اكتب الأمر `sandbar run test` وسط الجملة، وكذلك المسار `src/index.ts`؛ فكلاهما يظهر بالشكل الصحيح.

جملة فيها عبارة إنجليزية: يوضع Task File في جذر المشروع، وبعد تشغيل `sandbar list` تُطبع قائمة المهام.

كتلة الشيفرة تبقى من اليسار إلى اليمين حتى بين فقرتين عربيتين:

```bash
npx sandbar run build --dry-run
```

:::callout{type=tip title="تلميح"}
ضع اسم الأمر بين علامتي الاقتباس المائلتين ليحافظ على اتجاهه، واكتب الأرقام كما تظهر في مخرجات الأداة، مثل `--parallel 2`.
:::
