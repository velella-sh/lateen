نصب

این صفحه نصب ویجت را توضیح می‌دهد. کد زیر باید چپ‌به‌راست بماند:

npm install @example/widget

پشتیبان بگیرید

پیش از نصب یک نسخهٔ پشتیبان بگیرید.

macOS

brew install widget

Linux

curl -fsSL https://get.example.com | sh
متغیرها

این‌ها را پر کنید تا مقدارهایتان در نمونه‌های کد دیده شود. مقدارها در مرورگر شما می‌مانند.

یک نشانی معتبر وارد کنید؛ مثلاً https://example.com.
