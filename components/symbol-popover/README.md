# Symbol popover

Use `:symbol[runExample]{signature="runExample(): void" href="/reference/runner/"}` in running text or `::symbol-popover{name="runExample" signature="runExample(): void"}` on its own line.

The button opens a native popover with the signature and reference link. The island coordinates open panels with other theme popovers and keeps them within the viewport. Older browsers show the signature and link inline.
