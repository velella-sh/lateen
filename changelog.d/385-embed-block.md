- Embedding: the `embedded` layout renders a page as a small view for other sites to put in an `iframe`: no chrome, no script, `noindex`, a canonical link and a "full page" link that opens in the top window. `embedded` front matter sets `of`, `scheme` (`light`, `dark`, `auto`), `height` and `transparent`; the view follows the host's colour scheme and adapts from 240 to 720 pixels with CSS alone. The `embed-code` component shows the `iframe` code, a static HTML snippet and a Markdown snippet with copy buttons, a choice of published variants, and a preview that loads only on request.
