- CLI demo: `cli-demo` shows a terminal session with prompt, output, errors and comments as selectable text; "Copy commands" takes only the commands, "Copy all" takes the whole session, and `{play}` reveals lines on request. `install-tabs` shows one install command for several package managers, set with `installTabs.managers`, switching without JavaScript and remembering the choice. Both print in full and keep their meaning in forced-colors mode.
